# Decision 0001 — Foundation First, Project Data Private

## Konteks

Pemilik ingin sistem Dana Indonesiana 2025–2026 dengan pedoman modular dan seragam seperti repository sebelumnya, terutama PRD-Creator, tetapi belum memberikan detail kontrak atau data proyek.

## Keputusan

- Membuat **foundation documentation** dulu; belum membangun aplikasi atau menjalankan akuntansi.
- Mengadaptasi pola root router, canonical owners, source authority, proof boundaries, dan tiga branch.
- Menyimpan template kosong di repository publik; data kontrak, transaksi, dan dokumen asli di workspace privat.
- Menetapkan tiap regulasi sebagai kandidat sampai berlaku secara spesifik untuk proyek.
- Membuat sembilan batas domain logis tanpa memaksakan sembilan implementasi.
- Mengizinkan laporan turunan hanya dari catatan kanonis; approval resmi tidak boleh disimulasikan.
- Meminimalkan kompleksitas dan mencegah registry/status/agent duplikat.

## Alternatif yang ditolak untuk tahap ini

Membuat dashboard lengkap sebelum data diketahui; menyalin seluruh kode PRD-Creator atau MIVUBI Finance; menganggap pedoman 2026 berlaku otomatis; menggunakan GitHub publik sebagai bukti keuangan.

## Batas bukti

Keputusan ini mengesahkan **arah desain sistem** saja. Tidak membuktikan kelayakan aturan tertentu, kemampuan runtime, integrasi portal, atau kepatuhan proyek.
