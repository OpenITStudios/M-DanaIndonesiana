# Decision 0003 — Administration + Editorial Development Without More Skills

## Masalah

Fondasi skill v0.5 memusatkan hasil deterministik keuangan, namun pekerjaan administrasi dan pelaporan karya masih berisiko mencampurkan status dokumen, format pemerintah, fakta karya, dan hasil narasi. Membuat skill/agen baru untuk setiap jenis surat atau laporan akan menambah duplikasi aturan.

## Keputusan

1. Tetap **tujuh skill**. Pendalaman dilakukan di domain existing `administration` dan `writing` dengan dokumen owner yang jelas.
2. Administration mengelola **paket, versi, checklist, dan status**, tanpa menyebut kelengkapan sebagai persetujuan.
3. Writing memegang **makna dan redaksi**; bahan kuratorial berbeda dari bahasa pelaporan pemerintah, tetapi tidak boleh menghasilkan fakta tambahan.
4. Evidence/Finance/Regulatory/Production tetap pemilik bukti, angka, aturan, dan hasil. Draf lain merupakan proyeksi.
5. Template generik hanya dibuat jika benar-benar membantu produksi; tidak perlu folder kosong, registry ganda, atau dashboard sekarang.
6. Prinsip ANRI digunakan sebagai **referensi tata kelola arsip**, bukan mengeklaim penerapan aturan instansi pemerintah pada penerima manfaat.
7. Pengguna menunda pengujian: **tidak ada tes yang dijalankan** dalam pengembangan ini. Pengujian tercatat sebagai backlog yang tidak boleh dinyatakan PASS.

## Batas keamanan

Tidak ada data sensitif, kontrak, rekening, SPTJM, atau hasil dokumen yang diminta "hanya dipelajari" di repository publik. Perubahan ini hanya instruksi reusable dan template kosong.

## Penerimaan di masa depan

Tinjau kualitas naskah dari contoh sintetis melalui pembaca manusia dan pastikan daftar kelengkapan bertumpu pada sumber resmi. Pengujian baru dilakukan setelah pengguna meminta memulai fase QA.
