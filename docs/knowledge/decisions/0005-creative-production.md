# Decision 0005 — Source-Led Creative Production

Karya digital memerlukan jejak sumber kuratorial, artefak, hak pemanfaatan, dan hubungan dengan indikator yang disetujui. Jika progres tugas disamakan dengan capaian resmi atau screenshot disamakan dengan QA, laporan dapat menyesatkan.

**Keputusan:** tetap tujuh skill. `creative-production` memakai lima kontrak di domainnya; Writing, Evidence, Rights, Finance, Regulatory dan Administration memegang fakta masing-masing. Kemajuan internal tidak otomatis menjadi persentase resmi. Kuratorial membedakan fakta, interpretasi dan representasi. Rilis membedakan source, build, deployment dan arsip. UNESCO/Spectrum/WCAG/Minecraft dirujuk menurut jenis dan kewenangannya, tidak dijadikan aturan universal kontrak.

**Batas:** tidak ada database koleksi baru, approval/QA otomatis, file rahasia atau data proyek asli. **Pengujian sengaja ditunda** atas permintaan pengguna.
